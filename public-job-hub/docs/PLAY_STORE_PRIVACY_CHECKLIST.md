# Public Job Hub 출시 전 개인정보·Play Console 점검표

기준일: 2026-11-08

이 문서는 운영자가 실제 서비스 설정과 Google Play의 데이터 보안 설문을 대조하기 위한 내부 체크리스트다. 법률 자문을 대체하지 않는다.

## 공개 전에 반드시 확정할 항목

- [ ] 개인정보처리방침과 운영자 안내에 운영자의 실명 또는 사업자명 표시
- [ ] 이용자가 연락할 수 있는 개인정보 문의 이메일 표시
- [ ] Play Console의 개발자명·연락처와 웹 정책의 운영자 정보 일치
- [ ] `https://public-job-hub.duckdns.org/account-deletion` 공개 접근 및 삭제 절차 확인
- [ ] 회원 탈퇴 후 계정, 프로필, 스크랩, 지원 일정, 관심기관, 알림 토큰, 문의, 합격 후기, 로그인 기록 삭제 확인
- [ ] OCI 백업 수명주기 최대 56일 및 접근권한 확인
- [ ] TiDB, OCI, Firebase, Gmail의 실제 리전·계약·개인정보 조건이 방침과 일치하는지 확인
- [ ] 공공데이터 이용조건과 기관 로고의 표시·삭제 요청 절차 확인

## Google Play 데이터 보안 설문 초안

실제 출시 빌드와 서버 설정이 달라지면 아래 답변도 변경해야 한다.

| 데이터 범주 | 예시 | 수집 목적 | 필수 여부 | 삭제 |
| --- | --- | --- | --- | --- |
| 개인정보 | 이메일, 표시 이름 | 계정 관리, 인증, 안내 | 필수 | 탈퇴 시 운영 DB 삭제 |
| 사용자 콘텐츠 | 문의, 합격 후기, 메모 | 앱 기능, 고객지원 | 선택 | 사용자 삭제·탈퇴 시 삭제 |
| 직업·교육 정보 | 학위, 성적, 자격증, 경력, 대외활동 | 스펙 관리와 공고 매칭 | 선택 | 사용자 삭제·탈퇴 시 삭제 |
| 앱 활동 | 스크랩, 관심기관, 지원 단계와 일정, 알림 설정 | 앱 기능과 개인화 | 선택 | 사용자 삭제·탈퇴 시 삭제 |
| 기기·기타 식별자 | Firebase 푸시 토큰 | 알림 발송 | 선택 | 알림 해제·토큰 무효화·탈퇴 시 삭제 |
| 진단·보안 정보 | IP, User-Agent, 접속 시각, 오류 기록 | 보안, 장애 대응 | 서비스 이용 시 | 목적 달성·탈퇴 및 운영 기준에 따라 삭제 |

- 전송 중 암호화: HTTPS/TLS 적용 여부를 운영 환경에서 재확인한다.
- 비밀번호: 원문이 아닌 단방향 해시만 저장한다.
- 판매: 하지 않는다.
- 광고: 현재 광고 SDK와 맞춤 광고 추적을 사용하지 않는다.
- 공유: Firebase 등 처리업체 전송이 Google Play 정의상 ‘공유’ 예외에 해당하는지 최신 설문 안내에서 다시 확인한다.
- 삭제 요청: 앱 내부 회원 탈퇴와 외부 웹 삭제 안내를 모두 제공한다.
- 백업: 운영 DB에서 삭제된 데이터가 암호화 백업에 최대 56일 남을 수 있음을 공개한다.

## 기능별 검증 시나리오

1. 신규 계정에 학위·자격증·스크랩·관심기관·문의·합격 후기를 각각 하나씩 저장한다.
2. 푸시를 연결하고 테스트 알림을 수신한다.
3. 마이페이지에서 탈퇴한 뒤 같은 이메일로 로그인되지 않는지 확인한다.
4. DB에서 해당 사용자와 연결된 모든 테이블의 행이 0건인지 확인한다.
5. `/account-deletion`을 비로그인 상태와 모바일 화면에서 열어 절차가 명확한지 확인한다.
6. 이용약관·개인정보처리방침·데이터 출처 안내가 회원가입 전에도 열리는지 확인한다.
7. 공고 원문, 첨부파일, 로고의 출처와 오류 신고 기능을 표본 점검한다.

## 운영상 금지 사항

- 주민등록번호, 전화번호, 자격증 번호, 학위번호 등 서비스에 필요하지 않은 정보 입력을 유도하지 않는다.
- 운영 로그, DB 덤프, Firebase 서비스 계정 키, SMTP 앱 비밀번호를 저장소에 커밋하지 않는다.
- 실제 사업자·운영자 정보가 확정되지 않은 상태로 스토어 공개 출시를 진행하지 않는다.
- 이용 목적·처리업체·보유기간이 바뀌면 코드만 변경하지 말고 방침과 Play 설문을 함께 갱신한다.

# Public Job Hub 데이터 출처·권리 대장

기준일: 2026-11-20
목적: 서비스가 표시·가공·연결하는 외부 자료의 출처, 이용조건, 점검일과 조치 절차를 추적한다.

이 문서는 법률 자문을 대체하지 않는다. 운영자는 새 출처를 추가하거나 이용조건이 변경될 때 이 대장과 공개 `데이터 출처·이용 안내`를 함께 갱신해야 한다.

## 기관명·로고·첨부자료

- 기관명과 로고는 공고 출처 식별을 위한 최소 크기와 범위에서만 표시하며, 관리자 검수로 등록한 로고만 사용한다.
- 로고 표시는 제휴, 후원, 인증 또는 보증을 의미하지 않는다.
- 로고 파일을 편집하거나 서비스 자체 상표처럼 사용하지 않는다.
- 첨부자료는 원 제공기관의 다운로드 링크와 이용조건을 우선하며, 서비스 서버가 파일을 복제·재배포하지 않는다.
- 권리자가 수정·차단·삭제를 요청하면 요청자와 대상 권리를 확인한 후 해당 표시를 우선 숨기고 검토 기록을 남긴다.

## 권리침해·오류 대응 절차

1. 공고 오류 신고 또는 공지·Q&A로 대상 URL, 권리 또는 오류 내용, 요청 사항을 접수한다.
2. 관리자는 원문과 출처별 이용조건을 확인하고 필요하면 대상 표시를 임시 숨김 처리한다.
3. 정정, 링크 전환, 로고 교체 또는 삭제 결과를 요청자에게 알리고 관리자 감사 기록을 남긴다.
4. 같은 출처에 반복 문제가 생기면 자동 수집을 중단하고 허가 또는 공식 API를 확인한 뒤 재개한다.

## 출시 차단 확인 항목

- [ ] 공공데이터포털의 운영계정 활용 승인과 실제 API ID가 위 대장과 일치한다.
- [ ] JOB-ALIO 및 표본 기관의 최신 이용약관·robots.txt·저작권 표시를 다시 확인한다.
- [x] 권리 증빙이 없던 메인 배너 이미지를 제거하고 프로젝트 CSS로 직접 만든 배경으로 교체했다.
- [ ] 관리자 검수로 등록한 기관 로고 URL을 표본 점검하고, 출처 URL과 확인일을 별도 운영 기록에 남긴다.
